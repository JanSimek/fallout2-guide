# Installation

You need three things: a copy of Fallout 2, the **Restoration Project Updated** on top of it,
and a **modern engine** to run it with.

This guide assumes all three. The engine matters as much as the mod — it is what makes the
game run natively on current hardware, and it fixes a great many bugs of its own.

## 1. Get the game

Any retail copy works. The usual sources are [GOG](https://www.gog.com/game/fallout_2) and
Steam. Both ship the game pre-patched to 1.02; RPU handles everything beyond that, so you
do not need to hunt down any official patches yourself.

:::warning[Install on a clean game]
RPU **must** be installed over an unmodified Fallout 2. If you have previously installed
other mods, reinstall the game first. RPU already contains the Unofficial Patch, so do not
install that separately.
:::

## 2. Install RPU

Download the latest release from the
[RPU releases page](https://github.com/BGforgeNet/Fallout2_Restoration_Project/releases/latest).
At the time of writing that is **v2.4.34**.

### Windows

1. Download `rpu_v*.exe`.
2. Run it and point it at your Fallout 2 directory.
3. Pick your language and installer options (see [Installer options](#installer-options) below).
4. Install the engine (below), then launch `fallout2-ce.exe`.

### Linux and macOS

You can run the Windows installer under Wine, or install manually:

1. Download `rpu_v*.zip`.
2. If your filesystem is case-sensitive, lowercase the whole game directory recursively.
3. Extract the archive into the game directory, overwriting when asked.
4. Run `rpu-install.sh` (Linux) or `rpu-install.command` (macOS).

:::caution[Only if you launch the original executable under Wine]
You **must** set the DLL override, or sfall will not load and the mod will silently fail to
apply:

```bash
WINEDLLOVERRIDES='ddraw.dll=n,b' wine fallout2.exe
```

This does not apply to FOR:CE, which runs natively and does not use `ddraw.dll` at all.
:::

## 3. Install the engine

**Use [FOR:CE](https://github.com/fallout2-ce/fallout2-ce).** It is a complete
re-implementation of the Fallout 2 engine and it is what this guide assumes you are running —
on every platform, not just the ones where the original executable will not run.

Extract the release into your Fallout 2 directory and launch `fallout2-ce.exe` (or the
executable for your platform) instead of `fallout2.exe`.

**Why it is the default rather than a fallback:**

- **It runs natively** on Windows, macOS, Linux, Android and iOS. No Wine, no compatibility
  shims, no DLL overrides.
- **Dozens of engine-level bug fixes** that no data mod can reach, because they are in the
  executable rather than in the scripts.
- **High resolution is built in.** You do not need Mash's High Resolution Patch as a separate
  install.
- **Quality-of-life the original engine never had:** a two-column inventory, a four-row barter
  screen, an expanded AP bar, equipping companions directly instead of talking them into it,
  looting and bartering *as* a companion, ctrl-click to move items and auto-balance caps, music
  that continues across maps, doors that open on approach, and item and container highlighting.
- **RPU is explicitly supported**, as are the mods RPU bundles — NPC Armor, Party Orders,
  Talking Heads — and FO2tweaks (v14.5 or newer).

:::note[FOR:CE, not the original Fallout2-CE]
Searching for "fallout2-ce" will most likely land you on
[alexbatalov/fallout2-ce](https://github.com/alexbatalov/fallout2-ce), the original project. It
still has far more stars, but it has not seen a regular update in a long time.

**[FOR:CE](https://github.com/fallout2-ce/fallout2-ce) is the maintained fork** and the one to
install.
:::

:::caution[Sfall compatibility is broad, not total]
FOR:CE implements most of sfall's opcodes and hooks, and everything RPU needs. It is not a
100% reimplementation, and the project tracks the remaining gaps in
[SFALL_COMPATIBILITY.md](https://github.com/fallout2-ce/fallout2-ce/blob/main/SFALL_COMPATIBILITY.md).

In practice this affects mod authors far more than players. If something in this guide does
not match what you see, check [Known Issues](/reference/known-issues) first.
:::

### If you stay on the original executable

Everything in this guide still applies — the mod is the same. Two differences:

- Settings live in `ddraw.ini` and `f2_res.ini` rather than `fallout2.cfg`. See
  [Configuration](/getting-started/configuration).
- On Linux and macOS you will be running under Wine, with the DLL override above.

There is no content reason to prefer it.

## Installer options

The installer asks a number of questions. The ones worth thinking about:

| Option | Recommendation |
| --- | --- |
| **High resolution patch** | **Yes** on the original engine — not optional in practice, since parts of the EPA cannot be navigated at 640×480 without it. **Skip it on FOR:CE**, which has high resolution built in. |
| **Cassidy talking head** | Yes. A restored talking head with good voice work. |
| **New Lenny model** | Personal taste. He looks better but uses rifles instead of pistols and has no run animation, so he trails behind the party. |
| **New player model when boxing / ring fighting** | Cosmetic. Either is fine. |
| **NPC armor** | Yes. Companions visibly change appearance with the armour you give them, and it unlocks Dogmeat's kevlar armour in Broken Hills. |
| **Party orders** | Yes. Lets you give companions standing combat orders instead of fighting the AI. |
| **High quality music** | Yes, unless disk space is tight. |

After installation, `mods/rpu.ini` and `mods/upu.ini` in the game directory expose a large
number of individual toggles. See [Configuration](/getting-started/configuration).

## Recommended extras

These are not part of RPU but sit well on top of it:

- **[FO2tweaks](https://github.com/BGforgeNet/FO2tweaks)** — a menu of quality-of-life
  toggles (faster combat, better item highlighting, and so on).
- **[Inventory Filter](https://github.com/rotators/InventoryFilter)** — tabs for the
  inventory screen. By the midgame you will be carrying a great deal of junk.
- **[Lossless music](https://github.com/BGforgeNet/Fallout2-HQ-music)** — if you care.

## A note on saves

RPU requires a **new game**. You cannot install it over a save in progress. The one
exception is upgrading from an older RP or RPU version, which has its own
[procedure](https://github.com/BGforgeNet/Fallout2_Restoration_Project/blob/master/docs/update.md).

Keep several rotating saves. Fallout 2 has a number of points where a decision made twenty
minutes ago quietly closed off a quest, and a single save slot will not help you.
