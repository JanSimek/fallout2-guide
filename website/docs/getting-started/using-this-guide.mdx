# How to Use This Guide

## The guide describes RPU, not vanilla

Every page here describes the game as the **Restoration Project Updated** plays it. There is
no running commentary on what the 1998 release did differently, because for most of the game
the difference does not matter and the commentary would double the length of every page.

Where RPU changes something *substantially* — a quest with a new solution, a location that is
now reachable, a reward that has moved — you will see a marker:

> The rat god can be brought down by collapsing the cave on him.
> <Vanilla>The original game only lets you fight Keeng Ra'at, for 300 XP. RPU adds the
> destructible support beams and pays 600 XP for using them.</Vanilla>

Hover over the icon with a mouse, or tap it on a touchscreen. The guide text is always the
RPU version; the marker only ever holds historical context you can safely ignore.

## Quest names

Quest headings link to the [Fallout Wiki](https://fallout.fandom.com/wiki/Fallout_2_quests),
where you can check exact rewards, alternate solutions and the underlying script conditions:

> ### <Quest>Kill the rat god</Quest>

Quests that RPU adds have no wiki page, so they are marked but not linked:

> ### <Quest rpu>Fix the well for Marli and the tribe</Quest>

A full cross-referenced list lives on the [Quest Index](/reference/quest-index) page.

## Admonitions

:::note
Useful detail — a hidden item, an unobvious dialogue option, a shortcut.
:::

:::tip
A recommendation. Something that will make your life easier.
:::

:::caution
Something that can go wrong: a quest you can lock yourself out of, a check you get one
attempt at, an NPC who leaves permanently.
:::

:::danger
Something that will get you killed, or break a save.
:::

## Skill checks

Skill checks are written as the skill and the value you need, for example **Speech 76%**.
Unless stated otherwise:

- The number is the skill level at which you have a reasonable chance, not a guarantee.
- Most checks can be retried. Where a check is **one attempt only**, the text says so.
- Where a check is rolled *against* your skill (so higher is better but never certain), the
  text gives the rough odds, e.g. *repair 100% ≈ 50% chance*.

## Reading order

The [Walkthrough](/walkthrough/overview) is arranged in the order the game expects you to
travel, not alphabetically. If you follow it top to bottom you will arrive everywhere at
roughly the right level with roughly the right equipment.

You do not have to. Fallout 2 is open after Klamath, and the guide flags anywhere that
arriving early or late causes a problem.
