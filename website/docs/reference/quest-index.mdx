# Quest Index

**182 quests** — the 146 from the base game, linked to their
[Fallout Wiki](https://fallout.fandom.com/wiki/Fallout_2_quests) pages, plus the **36 that the
Restoration Project adds**, which have no wiki page and are marked instead.

Locations are in the order the [walkthrough](/walkthrough/overview) visits them.

:::tip
Quest names link to the wiki, where you can check exact rewards, alternate solutions and the
underlying script conditions. The guide pages describe how to actually do them.
:::
