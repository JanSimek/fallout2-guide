# To Check

Most of this guide is checked against the game's own files: RPU's scripts and dialogue, the item and
critter protos, and the [FOR:CE](https://github.com/fallout2-ce/fallout2-ce) engine source. This page
is the other part — what has **not** been settled, kept in the open rather than quietly asserted.

Two kinds of thing are listed:

- **Marked claims.** Anywhere you see the <Unverified>Like this one: an icon in the text, with a note
  saying what could not be confirmed.</Unverified> icon, the claim is on this list. Most are things a
  script cannot decide — how the engine behaves at runtime, or whether a bug still bites.
- **Open work**, below: whole areas that have not had the same treatment yet.

If you settle one at the keyboard, the fix is usually a one-line change on the page it came from.

## Open work

### The guide describes RPU 2.3; the object database is built from 2.4

The [companions section](/companions/overview) and everything in the
[object database](/database) were checked against **RPU v2.4.34**. The rest of the guide was written
against the 2.3 line, and in places against RPU changes that are in no release at all. Between 2.3.34
and 2.4.34, 194 map files change (Pixote's updated maps), along with scripts at the EPA, Sierra Army
Depot, Vault City and Vault Village.

**What needs doing:** re-check the walkthrough against 2.4.34, starting with those four locations and
with any direction that depends on where something sits on a map.

### Pages checked only where they mention companions

The walkthrough was corrected wherever a companion was involved, which is not the same as being
checked. Quest steps, XP figures, skill checks and directions that never mention a companion have not
been read against the scripts.

**What needs doing:** a page-by-page pass, in the order the walkthrough runs. `check-rpu-drift.py`
already catches quests and XP figures that no script awards; the rest is reading.

### Engine claims inherited from the 1998 executable

The guide inherited a set of bugs and tricks from Per Jorner's guide, written for the original
executable. Many are fixed in FOR:CE, and the audited ones say so — see
[Known Issues](/reference/known-issues). The rest are neither confirmed nor ruled out, because they
depend on runtime behaviour that reading the source does not settle; they are in the list below,
alongside everything else still open.

**What needs doing:** playing. Each of these is a save, a reload and five minutes.

### Nothing here has been verified in play

Every fact in this guide comes from reading the game's files and the engine's source. That is a good
way to get numbers and conditions right, and a poor way to notice that something does not work the
way the code implies. Where those two can disagree, the claim is marked.
