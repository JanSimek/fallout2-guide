# The Fallout 2 Guide

A complete walkthrough for **Fallout 2** as it plays with the
[Restoration Project Updated](https://github.com/BGforgeNet/Fallout2_Restoration_Project) (RPU).

Most Fallout 2 guides on the internet describe a game that nobody plays any more: the
unpatched 1998 release, full of broken quests, dead ends and content that was cut days
before the game shipped. RPU puts that content back, fixes the bugs, and quietly changes
enough quest logic that an old guide will send you looking for things that are no longer
there.

This guide is written the other way around. **Everything on these pages describes RPU
as it actually behaves.** Where the difference from the original game is large enough
that you might trip over it, there is a marker like this one <Vanilla>Hover or tap the
icon to see what the original game did. Small differences are not marked at all — the
guide simply describes the RPU version.</Vanilla> — hover over it, or tap it on a
touchscreen.

## What this guide covers

- **[Getting Started](/getting-started/installation)** — installing the game, the mod and a
  modern engine, and the handful of settings worth changing before you start.
- **[Character Creation](/character/overview)** — a full breakdown of SPECIAL, traits,
  skills and perks, plus builds that work. Read this before you roll a character; Fallout 2
  is unforgiving about a bad start.
- **[Walkthrough](/walkthrough/overview)** — every location, in a sensible playing order,
  quest by quest. All 182 quests are described here, and indexed on the
  [Quest Index](/reference/quest-index).
- **[Reference](/reference/quest-index)** — companions, combat, the car, items, random
  encounters, endings and the quest index.

## What it does not cover

Fallout 2 is a big, reactive game and this guide does not try to describe every possible
outcome of every conversation. It gives you a route through each area that works, tells
you where the meaningful choices are, and flags the places where a decision closes
something off permanently.

It also assumes you want to *play* the game. If you want an optimal-XP speedrun route,
this is the wrong document.

:::tip[Spoilers]
This is a walkthrough. It spoils everything. If this is your first Fallout 2, consider
reading only [Getting Started](/getting-started/installation) and
[Character Creation](/character/overview), then coming back when you get stuck.
:::
